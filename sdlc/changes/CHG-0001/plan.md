## Decisions baked into the scaffold
- Package names: `@sdlc/schemas`, `@sdlc/core`, `@sdlc/adapter-git` (dir `packages/adapters/git`), `@sdlc/cli`. All `private`.
- Modules: ESM everywhere (`"type": "module"`), `module`/`moduleResolution: NodeNext`, relative imports carry `.js`. `verbatimModuleSyntax` on.
- Strictness in `tsconfig.base.json`: `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noImplicitOverride`, `noFallthroughCasesInSwitch`, `isolatedModules`, `declaration` + `declarationMap` + `sourceMap`, `skipLibCheck`, `target ES2022`, `lib ES2023`, `types ["node"]`.
- Build: plain `tsc -b` with project references. Each package has `tsconfig.build.json` (composite, `src` -> `dist`) referenced from the root `tsconfig.json`, and a `tsconfig.json` (noEmit, includes `src` + `test`) for the editor and lint.
- Dependency direction encoded now in `package.json` + `references`: `schemas` <- `core` <- `adapter-git` <- `cli`. `core` declares no `dependencies` at all in 0.1.
- Tests: Vitest 4, one root `vitest.config.ts`, tests in `packages/**/test/*.test.ts`, `@sdlc/*` aliased to each package's `src/index.ts` so tests never need a prior build.
- Lint: ESLint 10 flat config, `typescript-eslint` `strict` (non-type-aware), `--max-warnings 0`. A `no-restricted-imports` block scoped to `packages/core/src/**` bans every Node builtin (`node:*` and bare names) — the mechanical form of "core has no I/O".
- Core placeholder test also asserts `packages/core/package.json` has no dependency outside the `@sdlc/` scope (blueprint §7.1 allows core -> schemas later; nothing else).
- Toolchain pins: pnpm 10.12.4 (`packageManager`), Node `>=22` (`engines`, `engine-strict`, `.node-version`), TypeScript ~6.0.3 (typescript-eslint 8.69 supports `<6.1`; TS 7 is out of range), Vitest ^4.1, ESLint ^10.9, typescript-eslint ^8.69, @types/node ^22.
- `.gitattributes`: `* text=auto eol=lf` plus `sdlc/**/log.jsonl merge=union`.
- Git: repo is not initialised yet. `git init -b main` explicitly (global `init.defaultBranch` is `my`). Three commits on `main`: baseline docs, plan.md, scaffold.
